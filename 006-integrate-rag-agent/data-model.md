# Data Model

This document describes the data model for the Q&A feature. The data model is based on the key entities identified in the feature specification.

## Entities

### Question

The user's query.

- **Type**: `string`
- **Validation**:
  - Must not be empty.
  - Must be a valid string.

### Answer

The response generated by the RAG agent.

- **Type**: `string`

### Source

A reference to the part of the book the answer was drawn from.

- **Type**: `object`
- **Properties**:
  - `title`: The title of the source document. (Type: `string`)
  - `url`: The URL of the source document. (Type: `string`)

### Matched Text Chunk

The specific text from the book that the RAG agent used to generate the answer.

- **Type**: `string`
