# Data Model for RAG Ingestion Pipeline

This document defines the data entities used in the RAG data ingestion pipeline, as derived from the feature specification.

## Entity: WebContent

Represents the content of a single page from the book's website.

- **Fields**:
    - `url` (string): The unique URL of the page.
    - `html_content` (string): The full raw HTML content of the page.
    - `cleaned_text` (string): The extracted plain text content from the main article of the page.

- **State Transitions**:
    1.  **Crawled**: The `url` and `html_content` are populated.
    2.  **Cleaned**: The `cleaned_text` is populated after processing `html_content`.

## Entity: EmbeddingVector

Represents a single text chunk and its corresponding vector embedding.

- **Fields**:
    - `text_chunk` (string): A segment of the `cleaned_text` from a `WebContent` entity.
    - `vector` (array of floats): The numerical embedding generated by the Cohere model.

## Entity: QdrantRecord

Represents a record to be stored in the Qdrant vector database. This is the final object that gets persisted.

- **Fields**:
    - `id` (string/UUID): A unique identifier for the record. This will be generated for each `EmbeddingVector`.
    - `vector` (array of floats): The embedding from the `EmbeddingVector`.
    - `payload` (object/dictionary): Metadata associated with the vector.
        - `text` (string): The `text_chunk` from the `EmbeddingVector`.
        - `source_url` (string): The original `url` from the `WebContent` entity.
