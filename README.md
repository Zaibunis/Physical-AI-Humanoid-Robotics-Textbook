# Physical AI & Humanoid Robotics Textbook

This project is part of Hackathon I: Create a Textbook for Teaching Physical AI & Humanoid Robotics Course. The goal is to develop a comprehensive textbook that teaches the fundamentals and advanced concepts of physical AI and humanoid robotics, deployed as a Docusaurus-based website with an integrated RAG chatbot.

## Overview

The future of work will be a partnership between people, intelligent agents (AI software), and robots. This shift won't necessarily eliminate jobs but will change what humans do, leading to a massive demand for new skills. This textbook aims to bridge that gap by providing comprehensive educational material on Physical AI & Humanoid Robotics.

## Project Goals

1. **AI/Spec-Driven Book Creation**: Write a comprehensive textbook using Docusaurus and deploy it to GitHub Pages using Spec-Kit Plus and Claude Code.

2. **Integrated RAG Chatbot Development**: Build and embed a Retrieval-Augmented Generation (RAG) chatbot within the published book that can answer user questions about the book's content.

## Technology Stack

- **Framework**: Docusaurus for documentation and textbook presentation
- **AI Tools**: Claude Code and Spec-Kit Plus for AI-driven content creation
- **Backend**: FastAPI for the RAG chatbot backend
- **Database**: Neon Serverless Postgres for data storage
- **Vector Storage**: Qdrant Cloud Free Tier for embeddings
- **Deployment**: GitHub Pages

## Project Structure

- `book/` - Contains the Docusaurus-based textbook project
- `specs/` - Specification files for the textbook content
- `history/` - Historical records and versioning information

## Features

- Interactive textbook with rich media content
- AI-powered RAG chatbot for answering questions
- Selective content querying for focused answers
- Modern, responsive web interface via Docusaurus
